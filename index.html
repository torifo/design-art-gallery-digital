HEX is a curatorial layer for on-chain generative art. We publish artist-signed contracts, host deterministic previews from the seed, and pin every output to IPFS. The code is the work — the JPEG is just a render.

No off-chain pricing. No reserve auctions hidden behind a form. Every drop ships with its source on GitHub, a verifier on Etherscan, and a license in the metadata. Built by engineers, for collectors who read source.
